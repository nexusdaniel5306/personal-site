Weakness Mining Engine

In progress, my capstone project in collaboration with CCC Intelligent Solutions

This semester, my team and I are building and researching self-improving agent harnesses.

In a nutshell, an agent harness is the environment and software which allows an LLM to use tools and pursue goals. Thus, the performance of an agent is dependent not only on the LLM, but also on the tooling and environment that it lives in. This increases the surface area for mistakes in the output of an agent; a faulty output can come from any tool or environment which the agent uses. Additionally, since the tools are independently developed from the agent, an update to a tool can change how an agent functions drastically.

Our goal is to help agents become more reliable by identifying where they struggle across many runs, what we call “weakness mining”.
